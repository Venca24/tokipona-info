# How to contribute

This project is open for external contributions in the form of either pull requests (preffered), or submitting issues (mainly if they are minor fixes or improvements and one is not familiar with development of web projects).

Hovewer, there are some basic points from which the project shouldn't deviate:
  * The main purpose of the project is to be the digital version of the book _toki pona en 76 ilustritaj lecionoj_ published in 2013 by Espero.
    * The main style of the content should adhere to the style of this book.
    * The content of the lessons in Esperanto should be firmly base on the content of this book with the exception of the additional excersises as they are not present in the original book. It is of course possible to correct typos and clear mistakes. Other language versions can be standard translations of the Esperanto version.
    * All assets (i.e. images, styles, scripts and/or fonts) need to be part of this project and not loaded from external providers.
    * The basic content of the resulting website should be accessible also for clients not using JavaScript.
