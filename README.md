# tokipona.info in Jekyll

## About the project

This project is reimplementation of the tokipona.info website as a static site generated by Jekyll.

## Getting started

1. Download the source code

        $ git clone git@github.com:Venca24/tokipona-info.git

2. Install the dependencies

        $ bundle install

3. Run the site on localhost

        $ jekyll serve

4. Go to `http://localhost:4000` in your browser.
